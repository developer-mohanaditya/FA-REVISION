# Financial Accounting Crash Course

> A local-first, static revision web application built for complete beginners with engineering backgrounds, preparing for the ESSEC Specialized Masters Financial Accounting (T0) exam. Grounded directly in course slides, Verdi and Windsurf exercise cases, and past examination papers.

---

## Quick Start (Run Locally)

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Start local development server
npm run dev

# 3. Open browser at http://localhost:5173
```

To run the automated validation test suite:
```bash
npm test
```

To create a production build:
```bash
npm run build
```

---

## Core Features

- **8 Course-Grounded Modules:** Faithful mapping of course sessions 1 through 7 into 8 structured revision modules.
- **9 Mandatory Sections per Module:**
  1. The Big Idea
  2. Why It Matters
  3. How It Works (with interactive accounting equation, T-accounts, and journal tables)
  4. How to Solve an Exam-Style Problem (with step-by-step reasoning and trap callouts)
  5. What Must I Remember? (with Master "Do Not Confuse" tables and formulas)
  6. Explain It Like I'm 10 (at subsection and module level)
  7. Check My Understanding (103 interactive questions with revealable solutions)
  8. Worksheet Bridge (connecting to original Verdi & Windsurf exercise files)
  9. One-Minute Recap (5 takeaways and 3 active recall prompts)
- **High-Yield Exam Mode (`/exam-mode`):** Master decision trees, formula cheat sheets, recurring journal-entry patterns, and a tactical 2.5-hour exam checklist.
- **Review Later Center (`/review-later`):** Bookmark questions you find tricky across any module and review them before the exam.
- **100% Offline & Local-First:** No accounts, no database, no backend server, zero analytics, zero external API keys.
